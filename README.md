# UAVape

Report and model-evidence repository for the UAVape dissertation.

Contents:

- `report/overleaf_draft_review/`: LaTeX report files and figure assets.
- `model_evidence/recovered_notebook/`: recovered UAVape model notebook.
- `model_evidence/runpod_artifacts/`: selected validation/model artifacts from RunPod runs.
- `model_evidence/generated_figures/`: generated report figures and supporting charts.

The large image datasets are not stored in this GitHub repository. They are intended to be shared separately through the OneDrive dataset bundle.
