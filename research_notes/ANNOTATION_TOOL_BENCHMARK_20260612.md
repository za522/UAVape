# Annotation Tool Benchmark for UAVape Dataset Construction

Research date: 12 June 2026.

This benchmark compares industry-standard computer-vision annotation tools against the practical requirements of the UAVape Dataset Construction Engine (DCE). The comparison focuses on whether each tool can support a small-object, object-detection workflow where data must be collected, labelled, quality-checked, exported to YOLO-compatible formats and iteratively improved through model feedback.

## Tool Set

The tools selected were: CVAT, Label Studio, Roboflow Annotate, Ultralytics Platform, Labelbox Annotate, Encord, V7 Darwin and Supervisely. These were chosen because they are widely used or commercially established platforms for computer-vision annotation, dataset management or AI-assisted labelling.

## Metric Justification Summary

The chosen metrics deliberately evaluate more than drawing capability. For UAVape, annotation is only one part of the data-construction problem. The DCE also needed to handle candidate image review, class-specific metadata, duplicate/quality screening, model-compatible export and iterative dataset improvement. This is why the benchmark includes deployment model, AI-assisted labelling, dataset/export fit, collaboration, quality assurance and small-object suitability.

## Synthesis

The audit shows that mature annotation tools already provide strong support for bounding boxes, polygons, segmentation masks, collaborative labelling and export. CVAT, Roboflow, Supervisely, V7 Darwin and Encord are particularly strong for computer-vision workflows, while Label Studio is strongest as a flexible open-source multimodal labelling framework. Ultralytics Platform is especially well aligned with YOLO training because its annotation, training and deployment workflow is native to YOLO tasks.

However, none of the reviewed platforms directly match the full UAVape DCE requirement without configuration or compromise. The DCE is not only an annotation interface; it is a domain-specific dataset-construction workflow for disposable vape litter. Its value lies in combining image review, vape/lighter-specific labelling, metadata capture, high-resolution export, synthetic/scraped data handling and model-ablation readiness. This justifies the development of a bespoke DCE even though existing tools remain valuable reference points.
